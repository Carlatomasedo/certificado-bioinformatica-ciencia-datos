Este repositorio contiene los archivos y actividades desarrollados durante las prácticas de la asignatura de Bioinformática. El proyecto está organizado en diferentes carpetas para facilitar la clasificación y el análisis de datos biológicos mediante herramientas Unix/Linux.

El contenido de esta carpeta es: 
datos_crudos/: contiene los datos originales utilizados en las prácticas, como muestras, secuencias de ADN en formato FASTA y archivos de análisis previos.
datos_procesados/: almacena los datos limpios y procesados, preparados para su posterior análisis.
scripts/: contiene los scripts y archivos con los comandos utilizados para realizar diferentes tareas de análisis.
resultados/: recoge los resultados finales obtenidos durante las prácticas.
documentacion/: incluye apuntes, notas y resúmenes relacionados con los contenidos y procedimientos realizados.
